# IEC 62443 Learning Hub

## Purpose

IEC 62443 is an international standard series for Industrial Automation and Control System (IACS) cybersecurity.

This repository documents my learning, implementation understanding, and requirement mappings for IEC 62443 in industrial and marine applications.

## Scope

### IEC 62443-3-2
System risk assessment and risk management.

### IEC 62443-3-3
System security requirements and security levels.

### IEC 62443-4-1
Secure product development lifecycle requirements.

### IEC 62443-4-2
Technical security requirements for components.

## Topics Covered

- Secure Development Lifecycle (SDL)
- Threat and Risk Assessment
- Security Levels (SL1-SL4)
- Authentication and Access Control
- Secure Update Management
- Vulnerability Handling
- Security Testing
- Documentation Requirements
- Security by Design

## Related Regulations

- EU Cyber Resilience Act (CRA)
- IEC 60092 (Marine Systems)
- IEC 61000 (EMC)
- IEC 60204-1
- ISO/IEC 27001

## Learning Goals

- Understand IEC 62443 requirements
- Create requirement matrices
- Build compliance evidence checklists
- Map controls to CRA requirements
- Apply cybersecurity concepts to marine communication and automation systems
